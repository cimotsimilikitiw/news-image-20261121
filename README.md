Deterministic Python 3.13 standard-library-only 1024x1024 broadsheet PNG renderer summarizing world news for Saturday, 21 November 2026.

## Usage

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

By default, `main.py` writes `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). An optional `--out <path>` argument is also accepted.
